## 1. Design Decisions

| Choice | Decision | Reason |
|--------|----------|--------|
| Plugin manager | `vim.pack` (Neovim built-in) | No extra dependencies; echasnovski guide (2026-03-13) |
| UI / editing toolkit | `mini.nvim` | Single repo, 40+ modules, minimal overhead |
| Completion | `blink.cmp` v1 | Fastest async completion in 2026; native snippet + LSP |
| Fuzzy finder | `telescope.nvim` + `fzf-native` | Familiar, massive ecosystem; rg powers grep |
| Color scheme | Tokyo Night (`night` variant) | Clean dark theme, full LSP/treesitter integration |
| LSP setup | Neovim 0.11+ native (`lsp/` folder + `vim.lsp.enable()`) | No mason overhead; manual server install per stack |
| Formatter | `conform.nvim` | Per-filetype (prettierd, black, gofumpt) with LSP fallback |
| Git hunks | `gitsigns.nvim` | Stage/reset/preview/blame — mini.diff is view-only |
| Font | Hurmit Nerd Font Mono | Set via `guifont` for GUI Neovim; set in terminal for terminal Neovim |

**Stack:** TypeScript + Node, TypeScript + React, Python, Go, Terraform, Markdown.

## 4. Files Created

### `init.lua`
Entry point. Loads modules in explicit order:
`options` → `keymaps` → `autocmds` → `plugins.pack` → `colorscheme` → `mini` → `treesitter` → `lsp` → `blink` → `telescope` → `lang.*` → `git` → `conform` → `hlslens` → `colorizer`

### `lua/options.lua`
`vim.opt` settings: relative numbers, 2-space indent, smart search, treesitter folding (foldlevel 99 = all open), clipboard=unnamedplus, `guifont = "Hurmit Nerd Font Mono:h13"`.

### `lua/keymaps.lua`
Leader = `<Space>`. Includes: window nav (`<C-hjkl>`), buffer nav (`<S-h>/<S-l>`), visual indent stay (`<`/`>`), save (`<C-s>` + `<leader>w`), clear search (`<Esc>`), paste without yank.

### `lua/autocmds.lua`
- Highlight on yank
- Trim trailing whitespace on save
- Resize splits on window resize
- Close certain filetypes with `q`
- Auto-create missing parent dirs on save
- Restore cursor position on buffer open
- Go: tabs + no expandtab; Python: 4-space indent

### `lua/plugins/pack.lua`
Single `vim.pack.add({...})` call with all plugin URLs. **Edit this file to add or remove plugins.**

### `lua/plugins/colorscheme.lua`
Tokyo Night `night` variant. Italic comments/keywords.

### `lua/plugins/mini.lua`
All 18 mini.nvim modules. Key detail: `mini.clue` and `mini.indentscope` use local `require()` references instead of the `Mini*` globals to avoid the "nil value" error (globals are set by `setup()`, but arguments are evaluated before `setup()` runs).

### `lua/plugins/treesitter.lua`
Uses the **new nvim-treesitter API** (Neovim 0.12+):
- `require("nvim-treesitter").setup({})` — no `configs` module
- `require("nvim-treesitter").install({...})` — async parser installation
- Highlighting is auto-enabled by the plugin's runtime files
- `nvim-treesitter-textobjects` configured with new explicit-function keymap API

### `lua/plugins/lsp.lua`
Enables servers via `vim.lsp.enable({...})`. `LspAttach` autocmd sets buffer-local keymaps, enables inlay hints, document highlight, and format-on-save for Go.

### `lua/plugins/blink.lua`
blink.cmp v1. Ghost text, auto-show docs, signature help, `mini.snippets` preset, sources: LSP > snippets > path > buffer.

### `lua/plugins/telescope.lua`
All `<leader>f*` keymaps. Also adds smart `<leader><space>` (git_files/find_files), `<leader>fP` (find in dir), `<leader>fD` (grep in dir), `<C-\>` buffers alias. `fzf` extension loaded with pcall guard.

### `lua/plugins/git.lua`
`gitsigns.nvim` with full hunk keymaps (`<leader>h*`), current-line blame, and `ih` text object. Replaces `mini.diff` (which was view-only).

### `lua/plugins/conform.lua`
`<leader>F` → conform format. prettierd for TS/JS/JSON/YAML/MD, black+isort for Python, gofumpt+goimports for Go, stylua for Lua, terraform_fmt for HCL. Format-on-save is **off by default** — commented template in file to enable per filetype.

### `lua/plugins/hlslens.lua`
Wraps `n`/`N`/`*`/`#`/`g*`/`g#` to show `[x/N]` match count overlay.

### `lua/plugins/colorizer.lua`
Inline color swatches for CSS, JSX, Tailwind, Lua, YAML, Terraform.

### `lua/plugins/markdown.lua`
Configures render-markdown.nvim to show rich preview formatting (headings, code blocks, tables, checkboxes) inline for Markdown and AI chat panels.

### `lua/plugins/claudecode.lua`
Embedded Claude Code sidebar controller. Integrates with the `claude` CLI WebSocket protocol to sync file edits and visual selections with cursor context.

### `lua/plugins/ai.lua`
AI developer tools: CodeCompanion chat and inline editing mapped to `<leader>ac`/`<leader>aa`/`<leader>ai`, and Windsurf ghost-text configuration using Alt-key bindings to prevent Tab conflicts.

### `lua/plugins/grug-far.lua`
Project-wide search and replace dashboard. Pre-fills searches using the word under cursor via `<leader>sw` and allows editing ripgrep arguments.

### `lua/plugins/harpoon.lua`
Quick bookmarks setup (harpoon2). Maps bookmarks to slots `<leader>m1-4` and handles list additions/menu navigation.

### `lua/plugins/trouble.lua`
Toggles visual lists of project diagnostics, buffer diagnostics, and document symbols using `<leader>xx`, `<leader>xb`, and `<leader>xs`.

### `lsp/*.lua`
Each file is a Neovim native LSP config (returned table with `cmd`, `filetypes`, `root_markers`, `settings`). Activated via `vim.lsp.enable()` in `plugins/lsp.lua`.

## 5. Errors Encountered and Fixes

### Error 1 — `MiniClue` nil value (mini.lua:140)

**Message:**
```
attempt to index global 'MiniClue' (a nil value)
```

**Cause:** Lua evaluates function arguments before calling the function. Inside `require("mini.clue").setup({ clues = { MiniClue.gen_clues.builtin_completion() } })`, the `MiniClue.gen_clues.*()` calls are evaluated as arguments — but `MiniClue` global is only set by `setup()` itself, so it's `nil` at that point. Same issue with `MiniIndentscope.gen_animation.none()`.

**Fix:** Use local module references instead of globals:
```lua
-- Before (broken):
require("mini.clue").setup({ clues = { MiniClue.gen_clues.g() } })

-- After (fixed):
local clue = require("mini.clue")
clue.setup({ clues = { clue.gen_clues.g() } })
```
Applied to both `mini.clue` and `mini.indentscope`.

---

### Error 2 — `nvim-treesitter.configs` not found (treesitter.lua:2)

**Message:**
```
module 'nvim-treesitter.configs' not found
```

**Cause:** nvim-treesitter was **completely rewritten** for Neovim 0.12+. The old `require("nvim-treesitter.configs").setup({...})` API no longer exists. The new version has no `configs.lua` — only `config.lua` (install_dir only) and a top-level `require("nvim-treesitter")` module.

**Fix:** Rewrote `treesitter.lua` to use the new API:
```lua
-- Old (broken):
require("nvim-treesitter.configs").setup({
  ensure_installed = {...},
  highlight = { enable = true },
  textobjects = { select = {...} },
})

-- New (fixed):
require("nvim-treesitter").setup({})          -- optional, changes install_dir only
require("nvim-treesitter").install({...})     -- async parser installation
-- highlighting is auto-enabled by runtime files
-- textobjects configured via nvim-treesitter-textobjects separately
```

`nvim-treesitter-textobjects` also has a new API — keymaps now use explicit function calls:
```lua
vim.keymap.set({"x","o"}, "af", function()
  require("nvim-treesitter-textobjects.select").select_textobject("@function.outer", "textobjects")
end)
```

---

### Error 3 — telescope fzf extension not compiled

**Message:**
```
'fzf' extension doesn't exist: .../libfzf.so (no such file)
```

**Cause:** `telescope-fzf-native.nvim` requires a one-time `make` compilation step to build the native C library.

**Fix:**
```bash
cd ~/.local/share/nvim/site/pack/core/opt/telescope-fzf-native.nvim && make
```

Also wrapped `telescope.load_extension("fzf")` in a `pcall` so a missing build never blocks startup.

---

### Warning — `jsonc` unsupported in new nvim-treesitter

**Message:**
```
[nvim-treesitter] warning: skipping unsupported language: jsonc
```

**Fix:** Removed `"jsonc"` from the install list in `treesitter.lua`. The `json` parser handles `.jsonc` files via filetype detection.
